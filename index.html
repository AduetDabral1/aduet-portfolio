About

From auditing financial records to engineering the pipelines that move them.

I'm Aduet Dabral, a Data professional based in Dehradun, India. My path started in statutory audit at Deloitte, validating financial datasets of up to 30M+ records, which is where I first learned that the hardest part of data work isn't the analysis, it's trusting the pipeline behind it.

That curiosity led me to AWS, where I spent over a year as a Cloud Support Associate resolving production database issues on RDS and Aurora: diagnosing performance bottlenecks, tuning workloads, and writing the playbooks other engineers relied on.

Now I build the systems I used to troubleshoot: cloud native ETL/ELT pipelines, dimensional warehouses, and analytics ready datasets using Python, PySpark, SQL and modern cloud platforms.
